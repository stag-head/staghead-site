Part 02 · Built

Demand history you can trust

Planning starts with what was really sold. ForecastCentral keeps its own demand history, fed from Business Central every night. It cleans the numbers without ever deleting the originals.

RolesDemand planner, planning administrator
EditionAll Business Central editions
SourceItem ledger entries, CSV import
§ 01 · What it does

Demand history in practice

  • 01

    Nightly feed

    New sales are picked up from the item ledger by entry number, so nothing is counted twice. A Build History Now action runs it on demand.

  • 02

    Weekly and monthly periods

    Demand is summarised by item, location and period. The planning engine and every chart read these summaries.

  • 03

    Clean without losing anything

    Exclude a one-off order with a reason, or let outliers above a set factor be capped. The original entry always stays, and you can include it again.

  • 04

    Customer groups for planning

    A planning group on the customer, separate from price groups and posting groups, because pricing and planning are different questions.

  • 05

    Import from a file

    Bring history from a previous system in a CSV. Rows are checked first, unknown items can be mapped with a unit-of-measure factor, and a reconciliation explains every difference.

  • 06

    Undo an import

    Delete an imported file and the entries it created go with it. Fix the file and load it again.

  • 07

    Demo data

    Generate 200 items with three years of seasonal history to try everything on, then remove it again without touching your own data.

§ 02 · In a real situation

The one-off project order

Example

A customer buys 4,000 units in a single week for a project that will not happen again. Left alone, it lifts the forecast for months.

The planner selects the entry and chooses Exclude with Reason, typing the project name. The weekly history shows the cleaned quantity, and the original sale is still there, marked as excluded. If the customer orders the same project again next year, one click includes it.
